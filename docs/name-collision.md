# Name check

The repository name **AgentHub** is already used by several unrelated public GitHub projects. The name is still retained for the first release because it matches the product identity and the owner namespace makes the canonical URL unambiguous:

`https://github.com/Ste2027/AgentHub`

If the project later needs a more searchable organization name, candidates include **AgentHub Desktop**, **AgentHub Local**, and **AgentDesk**. Renaming is intentionally left to a future maintainer decision so existing links are not changed silently.
